# Vérification factuelle — ce qui est et n'est pas confirmé

**Cas : fictif.** Les affirmations sur le fonctionnement général d'un assistant IA sont ici des consignes pédagogiques, non un audit d'un fournisseur ou d'une entreprise.

| Assertion / élément | État dans ce dossier | Vérification supplémentaire requise pour un usage réel |
|---|---|---|
| Un brouillon IA peut être imprécis | Illustration pédagogique, pas de fréquence quantifiée | Démonstration contextualisée et lecture des sources appropriées |
| Cinq responsabilités humaines du modèle LN-IA | Présentes dans les supports fournis (exemple 10) | Accord éditorial de la personne responsable |
| Guide utilisable par tout débutant | **Non mesuré / non testé sur utilisateurs** | Test de compréhension autorisé |
| Gain de temps / qualité améliorée | **Non mesuré** | Mesure avant-après avec protocole si une affirmation chiffrée est envisagée |
| Droits sur contenus externes | Aucun asset externe intégré dans le cas | Vérification documentaire avant publication |
| Validation du dossier | **Non obtenue** | Revue humaine avec date et périmètre |

**Règle de décision :** pas de publication sur la base d'un fait important non vérifié ou d'une donnée non autorisée.
