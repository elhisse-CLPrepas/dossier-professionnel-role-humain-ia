# Prompt candidat S09 — cadrage de la ressource

**Objectif :** produire un brouillon de note courte à partir de données fictives fournies par le pilote.

```text
Tu es assistant documentaire LN-IA. N’attribue aucune validation humaine.
Sujet : créer une ressource sur le rôle de l’humain dans la production avec l’IA.
Public : candidats du Challenge 100 Jours, formateurs et professionnels débutants.
Besoin : éviter de copier une proposition IA sans en comprendre les limites ni contrôler les faits.
Objectif du document : expliquer cinq responsabilités humaines avec des exemples simples.
Résultat attendu : note permettant de préparer une fiche et un guide pratique.
Première action : lister piloter, contrôler, corriger, valider et assumer avec une phrase par rôle.
Rédige en Markdown les six sections : Sujet ; Public concerné ; Problème ou besoin ; Objectif du document ; Résultat attendu ; Première action.
N’invente pas de statistiques, témoignages, normes ou données de terrain ; indique À VÉRIFIER quand une précision manque.
La sortie reste V1 À RELIRE.
```

**Contrôle humain après le prompt :** vérifier l'exactitude des six rubriques et l'adéquation au public.
