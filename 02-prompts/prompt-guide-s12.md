# Prompt candidat S12 — plan → guide V1 puis révision V2

**Entrées :** note S09, fiche S10 et plan S11. **Le modèle n'a pas d'autorité de validation.**

```text
Tu es rédacteur pédagogique LN-IA. À partir des sources fournies, écris un guide concret « Le rôle de l'humain dans la production avec l'IA » pour des débutants.
Organise la lecture selon Comprendre, Préparer, Produire, Vérifier, Améliorer. Décris au moins trois actions numérotées avec un résultat à vérifier pour chacune ; détaille les cinq responsabilités humaines : piloter, contrôler, corriger, faire valider par une personne habilitée si requis, assumer et tracer.
Ajoute les erreurs à éviter, une checklist, les points À VÉRIFIER, la prochaine amélioration.
N'invente aucun gain mesuré ni vérification indépendante ; les situations restent fictives.
La sortie est une V1 À RELIRE, pas une procédure métier autorisée.
```

## Prompt de révision

```text
Lis ma V1 sans l'écraser. Propose une V2 réellement différente : explicite un arrêt de publication en cas de faits invérifiables, transforme le contrôle vague en contrôle traçable, distingue la correction de fond de la correction de forme, clarifie qui peut attribuer le statut VALIDÉ.
Fournis la V2 intégrale, puis un journal avant/après + motif et vérifications restantes. Ne prétends jamais avoir effectué une validation humaine.
```

**Après génération :** inspecter le `diff` V1/V2 et renseigner le journal de correction ; requérir une décision humaine avant diffusion.
